# Personal Portfolio Website

A responsive personal portfolio website developed for **IT ELEC 4 – Web Systems and Technologies 2**.

## Features & Sections
- **Home:** Introduction and quick navigation links.
- **About:** Academic background and development interests.
- **Skills:** Overview of web, mobile, game development, database, and design tools.
- **Projects:** Showcase of completed systems and applications.
- **Achievements:** Academic milestones and certifications.
- **Contact:** Direct links for email and GitHub profile.

## Technologies Used
- **HTML5**
- **CSS3** (Flexbox, CSS Grid, Media Queries for responsiveness)
- **JavaScript** (DOM manipulation for mobile navigation)

## Deployment
- Source Code hosted on **GitHub**
- Live Website deployed via **Vercel**
